# Agent notes

- Git commits: do not add `Co-Authored-By` trailers, `Generated with ...` lines, or any other AI/agent attribution to commit messages. All commits are authored and attributed solely to the repo owner.
- Do not create or push git notes (`refs/notes/*`) for this repository.
- This repository is excluded from git-ai tracking (`exclude_repositories`); keep it that way.

## Project

Parametric joinery projects (OpenSCAD + Fusion 360), sliced print files, interactive case studies, and agent skills — served by an Astro site. Skills install via `npx skills add`.

## Commands

- Dev server: `npm run dev`
- Build: `npm run build`
